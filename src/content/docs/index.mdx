## Why varsha?

varsha is a premium website starter template built on Astro by [myndlabs.tech](https://myndlabs.tech). It is designed for founders, indie hackers, and teams who want a production-quality marketing site without spending weeks on design, accessibility, and infrastructure.

<CardGrid>
  <Card title="Beautiful by default">
    A carefully crafted design system with 18+ built-in themes (Tokyo Night, Catppuccin, Nord, Dracula, Gruvbox, and more), refined typography, and premium component patterns.
  </Card>
  <Card title="Built-in docs & blog">
    Starlight-powered documentation with full-text search, sidebar navigation, and i18n (English, Japanese, Simplified Chinese). A content-collections blog with MDX support, tags, and RSS.
  </Card>
  <Card title="Zero-config deployment">
    First-class support for Vercel, Netlify, and Cloudflare Pages. Sitemaps, OG images, SEO metadata, and robots.txt work out of the box.
  </Card>
  <Card title="Agent-friendly">
    Ships with a dedicated agent skill file so AI coding assistants (TRAE, Cursor, Copilot) understand the project structure, conventions, and components from day one.
  </Card>
</CardGrid>
