## 预装集成

  <Card title="Starlight" icon="book-open">

  </Card>
  <Card title="Vercel" icon="triangle-up">

  </Card>

## Starlight 文档

Starlight 驱动文档站点（`/docs/`），在 `astro.config.mjs` 中配置：

```js title="astro.config.mjs"
starlight({
  title: 'varsha',
  customCss: ['./src/styles/global.css', './src/styles/marketing.css'],
  sidebar: [
    { label: 'Start here', items: [/* ... */] },
  ],
  locales: {
    root: { label: 'English', lang: 'en' },
    ja: { label: '日本語', lang: 'ja' },
    'zh-cn': { label: '简体中文', lang: 'zh-CN' },
  },
  social: {
    github: 'https://github.com/yethikrishna/web-ui-template',
  },
})
```

## Sitemap

`@astrojs/sitemap` 集成在构建时自动生成站点地图。在 `astro.config.mjs` 中配置：

```js
sitemap({
  filter: (page) => !page.includes('/admin/'),
  changefreq: 'weekly',
  priority: 0.7,
})
```

## Vercel 适配器

Vercel 适配器为 Vercel 平台优化构建。部署到其他平台时，切换适配器：

<Tabs>
  <TabItem label="Netlify">

  </TabItem>
  <TabItem label="Cloudflare">
    ```bash
    npx astro add cloudflare
    ```
  </TabItem>
  <TabItem label="Node.js">
    ```bash
    npx astro add node
    ```
  </TabItem>
</Tabs>

## 添加集成

添加 Astro 集成的最简单方式是使用 Astro CLI：

```bash
npx astro add <integration-name>
```

这会自动安装依赖并更新 `astro.config.mjs`。
