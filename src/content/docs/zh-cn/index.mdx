## 为什么选择 varsha

varsha 是由 [myndlabs.tech](https://myndlabs.tech) 开发的基于 Astro 的优质网站启动模板，专为希望无需在设计、可访问性和基础设施上花费数周时间即可构建生产级营销网站的创始人、独立开发者和团队而设计。

<CardGrid>
  <Card title="默认即美观">
    精心打磨的设计系统，内置 18+ 主题（Tokyo Night、Catppuccin、Nord、Dracula、Gruvbox 等）、精致排版和高品质组件模式。
  </Card>
  <Card title="内置文档与博客">
    基于 Starlight 的文档系统，支持全文搜索、版本管理、国际化（英文、日文、简体中文）。支持 MDX 的内容集合博客。
  </Card>
  <Card title="零配置部署">
    一流支持 Vercel、Netlify、Cloudflare Pages。站点地图、OG 图片、SEO 元数据、robots.txt 开箱即用。
  </Card>
  <Card title="AI 代理友好">
    附带专门的 Agent Skill 文件，让 AI 编码助手（TRAE、Cursor、Copilot）从第一天起就能理解项目结构、约定和组件。
  </Card>
</CardGrid>
