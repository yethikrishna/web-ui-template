## 为什么选择 varsha 构建

- **默认零 JS：** 快速加载，无膨胀
- **18+ 主题：** 开箱即用的美观配色方案
- **内置 i18n：** 支持英语、日语和简体中文
- **SEO 就绪：** OG 标签、站点地图、结构化数据
- **AI 就绪：** 附带 SKILL.md 用于 AI 编码代理
- **署名支持：** "Built with varsha by myndlabs" 归属支持持续开发

## 开始构建

```bash
npx degit yethikrishna/web-ui-template my-site
cd my-site
npm install
npm run dev
```
