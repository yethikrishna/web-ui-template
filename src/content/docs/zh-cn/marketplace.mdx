## 启动模板变体

varsha 可作为多种网站类型的起点：

### 极简博客

删除营销页面，专注博客。保留 `MarketingLayout` 用于博客列表和文章页面，自定义为博客主题。

### 文档优先站点

以 Starlight 文档为主，添加最少的营销落地页。适合开源项目和 API 文档。

### 完整营销站点

完整使用所有营销组件 — Hero、功能、定价、评价、CTA、博客、文档。适合 SaaS 和产品。

## 构建示例

以下是展示不同 varsha 功能的代码片段：

### 简单落地页

```astro
---
import MarketingLayout from '../components/MarketingLayout.astro';
---
<MarketingLayout title="My Product" description="..." canonicalPath="/">
  <main class="page">
    <section class="hero">
      <h1>Ship faster.</h1>
      <p>The all-in-one platform for builders.</p>
      <a href="/docs/install/" class="btn btn-primary">Get started</a>
    </section>
  </main>
</MarketingLayout>
```

### 博客索引页面

```astro
---
import { getCollection } from 'astro:content';
import MarketingLayout from '../../components/MarketingLayout.astro';
const posts = await getCollection('blog');
---
<MarketingLayout title="Blog" description="..." canonicalPath="/blog/">
  <main class="page">
    <section class="section">
      <div class="container">
        <h1>Blog</h1>
        {posts.map(post => (
          <article>
            <h2><a href={`/blog/${post.slug}/`}>{post.data.title}</a></h2>
            <p>{post.data.description}</p>
          </article>
        ))}
      </div>
    </section>
  </main>
</MarketingLayout>
```
