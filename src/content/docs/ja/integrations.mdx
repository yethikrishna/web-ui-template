## Starlightドキュメント

Starlightはドキュメントサイト（`/docs/`）を強化します。`astro.config.mjs`で設定されます：

```js title="astro.config.mjs"
starlight({
  title: 'varsha',
  description: 'A premium website starter template.',
  customCss: ['./src/styles/global.css', './src/styles/marketing.css'],
  sidebar: [
    { label: 'Start here', items: [/* ... */] },
    { label: 'Building your site', items: [/* ... */] },
    { label: 'Going live', items: [/* ... */] },
    { label: 'Reference', items: [/* ... */] },
  ],
  locales: {
    root: { label: 'English', lang: 'en' },
    ja: { label: '日本語', lang: 'ja' },
    'zh-cn': { label: '简体中文', lang: 'zh-CN' },
  },
  social: {
    github: 'https://github.com/yethikrishna/web-ui-template',
  },
})
```

### Starlightの機能

- **全文検索：** クライアントサイドの検索でドキュメントをすばやく見つける
- **i18n：** 多言語ドキュメント（英語、日本語、簡体字中国語が付属）
- **コードハイライト：** Shikiによるシンタックスハイライト
- **テーマ：** Starlightのテーマはvarshaのテーマシステムと連携

## Sitemap

`@astrojs/sitemap`インテグレーションはビルド時に自動的にサイトマップを生成します。`astro.config.mjs`で`sitemap.xml`に含まれるページを設定できます：

```js title="astro.config.mjs"
sitemap({
  filter: (page) => !page.includes('/admin/'),
  changefreq: 'weekly',
  priority: 0.7,
})
```

## Vercelアダプター

VercelアダプターはVercelプラットフォーム向けにビルドを最適化します。別のプラットフォームにデプロイする場合は、アダプターを切り替えてください：

## インテグレーションの追加

Astroインテグレーションを追加するには、Astro CLIを使用するのが最も簡単です：

```bash
npx astro add <integration-name>
```

これにより、依存関係が自動的にインストールされ、`astro.config.mjs`が更新されます。
