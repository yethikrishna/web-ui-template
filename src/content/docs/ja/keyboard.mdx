varshaには厳選された18以上のカラーテーマが付属しており、ボタンクリックまたはキーボードショートカットで即座に切り替えられます。すべてのテーマはマーケティングページとStarlightドキュメントの両方に適用されます。

## テーマの切り替え

テーマスイッチャーを開くには2つの方法があります：

1. 任意のページのナビゲーションにあるテーマボタン（パレットアイコン）をクリック
2. 任意のページで`/`または`t`を押す

テーマを選択すると即座に適用され、`localStorage`に保存されるため、次回アクセス時にも選択したテーマが維持されます。

## デフォルトテーマの設定

デフォルトテーマを変更するには、`src/styles/global.css`の`:root`セレクタを更新します：

```css title="src/styles/global.css"
:root {
  /* デフォルトをnordに設定 */
  --color-bg: #2e3440;
  --color-fg: #d8dee9;
  --color-muted: #a3be8c;
  --color-accent: #88c0d0;
  --color-surface: #3b4252;
  --color-border: #4c566a;
}
```

または、ThemeSwitcherのJavaScriptを変更してデフォルトを設定します。

## カスタムテーマの作成

独自のテーマを作成するには、`src/styles/global.css`に新しいCSSセレクタを追加します：

```css title="src/styles/global.css"
:root[data-theme="my-brand"] {
  --color-bg: #0f172a;        /* ページ背景 */
  --color-fg: #f1f5f9;        /* メインテキスト */
  --color-muted: #94a3b8;     /* セカンダリテキスト */
  --color-accent: #6366f1;    /* リンクとボタン */
  --color-surface: #1e293b;   /* カードの背景 */
  --color-border: #334155;    /* 境界線 */
}
```

次に、ThemeSwitcherコンポーネント（`src/components/ThemeSwitcher.astro`）にテーマを追加します：

```astro title="src/components/ThemeSwitcher.astro"
const themes = [
  // 既存のテーマ...
  { id: 'my-brand', name: 'My Brand', type: 'dark' },
];
```

### テーマデザインのヒント

1. **コントラスト比を確認する：** テキストと背景のコントラストは少なくとも4.5:1（WCAG AA）にする
2. **既存のテーマから始める：** 近いテーマをコピーして値を調整する
3. **両方のモードをテストする：** ダークとライトの両方のバリアントを作成する
4. **ドキュメントでテストする：** マーケティングページとドキュメントの両方でテーマが良く見えることを確認する
5. **アクセントカラーを控えめに：** アクセントカラーはボタンとリンクに使用 — 支配的すぎないように

## ライト/ダークモードの動作

- ユーザーが明示的にテーマを選択すると、その選択が保存されます
- 初回訪問時は、システムの`prefers-color-scheme`設定を尊重する場合があります
- デフォルトはTokyo Night（ダーク）です
