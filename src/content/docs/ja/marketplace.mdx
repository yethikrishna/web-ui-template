## 一般的なサイトパターン

### 最小限のランディングページ

ヒーロー、3〜4のフィーチャーカード、CTAセクション、フッターのみを使用：

```astro
<MarketingLayout title="My App" description="..." canonicalPath="/">
  <main class="page">
    <section class="hero">
      <h1>Ship faster.</h1>
      <p>Simple, beautiful apps.</p>
      <a href="/signup" class="btn btn-primary">Get started</a>
    </section>
    <section class="section">
      <div class="container">
        <div class="card-grid">
          <div class="card"><h3>Fast</h3><p>Lightning speed.</p></div>
          <div class="card"><h3>Simple</h3><p>Easy to use.</p></div>
          <div class="card"><h3>Beautiful</h3><p>Gorgeous themes.</p></div>
        </div>
      </div>
    </section>
  </main>
</MarketingLayout>
```

### ブログメインのサイト

ブログに焦点を当て、マーケティングセクションを減らし、ホームページでブログ記事を紹介します。`src/content/blog/`に記事を追加し、必要に応じてブログレイアウトをカスタマイズします。

### プロダクトドキュメント

製品中心のサイトの場合は、ナビゲーションとホームページを`/docs/`に向け、Starlightサイドバーを充実させます。

  </Card>

  </Card>
</CardGrid>
