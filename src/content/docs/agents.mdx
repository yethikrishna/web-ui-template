## Why teams choose varsha

Sites built with varsha share common characteristics:

- **Fast by default** — Static generation, zero unnecessary JavaScript, optimized fonts
- **Beautiful out of the box** — 18+ themes, refined typography, and a cohesive design system
- **Complete** — Marketing pages, docs, blog, and theme switching without cobbling plugins together
- **Accessible** — Semantic HTML, keyboard navigation, sufficient contrast, ARIA labels
- **Customizable** — Every color, font, and spacing value is a CSS token you can override

## Submit your site

If you have built a site with varsha, you can submit it for inclusion in the showcase:

1. **Instagram:** Tag [@yethikrishnar](https://instagram.com/yethikrishnar) with a screenshot or link
2. **GitHub:** Open a pull request on [github.com/yethikrishna/web-ui-template](https://github.com/yethikrishna/web-ui-template) adding your site to this page
3. **Social:** Post your site with the hashtag `#builtwithvarsha`

We review all submissions and feature sites that demonstrate interesting customizations, unique use cases, or exceptional design.

## What we look for

When selecting sites for the showcase, we consider:

- **Design quality** — Thoughtful customization of varsha's design system
- **Originality** — Unique layouts, custom components, or creative use of themes
- **Performance** — Fast loads and good Core Web Vitals
- **Content quality** — Well-written copy, clear messaging, useful content
- **Accessibility** — Sites that maintain varsha's accessibility standards
