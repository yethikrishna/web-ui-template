# varsha website starter

This skill teaches a coding agent to operate the varsha website starter template by myndlabs.tech.

## When to use

- The user wants to edit docs (`src/content/docs/`), the blog
  (`src/content/blog/`), or marketing pages (`src/pages/`).
- The user wants to rebrand, customize, deploy, or generate content for a varsha-based site.
- The user asks how the site is built or where something lives.

## Repository map

- `astro.config.mjs` — Astro + Starlight config: `site`, `title`, locales
  (`root`, `ja`, `zh-cn`), sidebar, social links (GitHub, Instagram), OG tags,
  first-visit locale redirect, and static output (no adapter).
- `index.html` — Root homepage (standalone HTML, not Astro).
- `src/content/docs/` — Starlight docs. `index.mdx` is the overview page;
  `ja/` and `zh-cn/` are translations. `docs/preview/` is generated by the
  build (mirrors stable docs). New file: `design-system.mdx`.
- `src/content/blog/` — blog posts (`*.md`) with `title`, `description`,
  `publishDate`, `author` frontmatter.
- `src/pages/` — `index.astro` (renders root `index.html`), `plugins.astro` (Showcase),
  `stats.astro` (Performance), `compare.astro` (Features standalone HTML), `blog/`.
- `src/components/` — Starlight overrides (`Header`, `Banner`, `Sidebar`,
  `SiteTitle`, `Footer`) and `MarketingLayout`, `AuthorCard`, `BuiltWith`.
- `src/styles/` — `starlight.css` (design system overrides) plus global CSS.
- `css/style.css` — Global stylesheet for marketing pages (18+ palettes, components).
- `scripts/prepare-docs.mjs` — Copies assets to `public/`, mirrors stable docs into
  `/docs/preview/`, and generates `public/llms.txt` and `public/llms-full.txt`.
  Runs before `dev` and `build`.
- `scripts/rebrand.mjs` — Idempotent find/replace of branding tokens
  (varsha / myndlabs.tech / yethikrishna/web-ui-template). Preserves attribution
  blocks between `<!-- varsha-builtwith:start -->` and `<!-- varsha-builtwith:end -->` markers.
- `vercel.json` — redirects and cache headers for Vercel deploy.
- `install.sh` / `install.ps1` — One-line installer scripts (degit/git clone).
- `create-varsha/` — Official CLI scaffolding tool (`npx create-varsha`), publishable to npm/JSR.

## Commands

```bash
npm install
npm run dev      # prepare docs + astro dev
npm run build    # prepare docs + astro build -> dist/
npm run preview  # preview the production build
node scripts/rebrand.mjs   # re-apply placeholder branding
```

## Attribution requirement

Every site built with varsha includes a "Built with varsha by myndlabs" credit linking to https://myndlabs.tech. This credit is protected and MUST be preserved:

- It lives between `<!-- varsha-builtwith:start -->` and `<!-- varsha-builtwith:end -->` markers
- CSS is protected between `/* varsha-builtwith:start */` and `/* varsha-builtwith:end */` markers
- A client-side self-healing script re-injects the credit if removed
- The rebrand script preserves protected blocks during customization
- Do NOT remove, hide, or obfuscate this credit

For white-label/commercial licensing: hey@myndlabs.tech

## Deployment

The repo uses `output: static` with no adapter — pure static output. Deploy with Vercel,
Netlify, Cloudflare Pages, GitHub Pages, or any static host. See `/docs/persistence-remote/` for details.
