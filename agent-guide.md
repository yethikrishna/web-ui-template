# varsha agent guide

You are reading this because a human asked you to help them understand, set up,
or build with this website starter template. This file gives you the concept
model and the setup path so you can guide them accurately. Canonical
documentation lives at https://myndlabs.tech/docs/ — link the human there for
depth, and verify any command you are unsure about against those pages instead
of guessing.

If you are running *inside* a coding session that uses this template's
tooling, the project ships a skill file that teaches you to operate it:
https://raw.githubusercontent.com/yethikrishna/web-ui-template/main/SKILL.md.
That file is about you operating the tooling; this file is about you teaching a
human.

## What this template is

varsha is a premium website starter template by myndlabs.tech, built with Astro and
Starlight. It ships:

- A beautiful marketing homepage with 18+ color palettes and dark mode
- A documentation site with English, Japanese, and Simplified Chinese locales
- Marketing pages: Features, Showcase, Performance, and blog
- A blog system under `src/content/blog/`
- A complete design system with CSS tokens and reusable components
- Built-in SEO (sitemap, OG tags, robots.txt, structured data)
- Machine-readable context for LLM agents: `public/llms.txt`,
  `public/llms-full.txt`, and `public/SKILL.md`, regenerated by
  `scripts/prepare-docs.mjs` on every `dev`/`build`.

## Concept model

- **Homepage** — `index.html` at the root (standalone HTML, not Astro).
- **Docs** — `src/content/docs/` holds Starlight markdown/MDX. `index.mdx` is the
  docs overview; each locale lives under `ja/` and `zh-cn/`.
- **Blog** — `src/content/blog/*.md` are blog posts collected by content config.
- **Pages** — `src/pages/` are Astro routes (Features, Showcase, Performance, blog).
- **Components** — `src/components/` override Starlight's `Header`, `Banner`,
  `Sidebar`, `SiteTitle`, and `Footer`, plus shared `MarketingLayout`, `AuthorCard`,
  and `BuiltWith` (the persistent attribution component).
- **Build** — `npm run build` runs `prepare-docs.mjs` (copies assets, mirrors docs into
  `/docs/preview/`, generates LLM context files), then `astro build`.

## Setup

```bash
npx degit yethikrishna/web-ui-template my-site
cd my-site
npm install
npm run dev      # local dev server at localhost:4321
npm run build    # static production build to dist/
npm run preview  # preview the production build
```

One-line installers:
- macOS/Linux: `curl -fsSL https://myndlabs.tech/install.sh | sh`
- Windows: `irm https://myndlabs.tech/install.ps1 | iex`

## Customizing

1. Update `astro.config.mjs` — `site`, `title`, `description`, social links.
2. Replace assets (`assets/logo.svg`, `assets/favicon.svg`, `assets/og-card-v8.png`) with your own brand.
3. Rewrite `index.html` hero and marketing copy for your product.
4. Edit `src/content/docs/*` and `src/content/blog/*` content.
5. Customize colors via CSS custom properties in `css/style.css`.
